Find by VIN

Decodes US VINs and European FINs using Mercedes' own tables. Nothing is sent anywhere — the lookup is local.

Import data

Pick a folder on this PC that holds manuals: an HTML manual archive, a Mercedes WIS corpus from the extractor (records.jsonl + manifest.json), or a folder of HTML / text / PDF files. The format is detected for you.

Starts the VM headless, reads the Mercedes database (read only), then shuts it down and rebuilds the Mercedes part of the index. It never takes snapshots or changes the VM's settings. A first full run takes several hours (images are pulled in batches with the VM off in between); a re-run skips what is already pulled.

Settings

Stored locally in ~/.autorundown/config.json. The key is sent only to Anthropic.
