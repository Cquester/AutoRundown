How LEMON downloads will work
  • What the torrent holds. LEMON's torrent is not one folder per car. All the text of every car is in one 31.5 GB file and all the images in one 481 GB file, stored by content, not by vehicle, so one car's pages are spread through the whole file.
  • Text. The text of any car needs most of that 31.5 GB file. Pages are shared between cars, so picking 78 variants costs about the same as picking one: pick everything you want first, then download once.
  • Images. Only the parts of the image file holding your picked cars' diagrams are downloaded — measured at about 10 GB for a 2015 F-150 (its images themselves are about 600 MB). Similar cars share most of those parts.
  • You see the size first. The download, the free space it needs and what stays on disk afterwards are shown before anything starts; it won't start without the space.
  • Nothing is left behind. After the import, the torrent files are deleted. Only the index and your picked cars' own images stay (in AutoRundown's folder; removing a car deletes them too). A setting can keep the 31.5 GB text file instead, so adding cars later doesn't download it again.
  • Nothing stays open. It never seeds: uploading is capped while it downloads, and the connection and its port close when it finishes.
  • Only the torrent. Nothing is fetched from the LEMON website itself.

Snapshots and rolling back

Before each run and each VM test AutoRundown takes a snapshot of the VM (at most one every 6 hours). If a run leaves Windows broken, roll back to the one taken before it. Rolling back first takes a snapshot of the VM as it is, so it can be undone. AutoRundown never deletes snapshots: tidy old ones up in VirtualBox.

    Models in the question box's menu
    Every model of each provider with a key is offered; untick the ones you don't want, to keep the menu short. The default is always offered.

    Mechanics' keys

    Make one Anthropic key per mechanic (“Get a key” above), load it with credit, and enter it here with the amount loaded. Keys are kept per provider: switching provider needs a key for that provider. Remaining is AutoRundown's own estimate: the amount you entered minus what AutoRundown logged on that key since. The provider doesn't tell an ordinary API key its balance, so check its console for the real figure. When you add credit or swap the key, use “Topped up / new key” so the count starts again.
